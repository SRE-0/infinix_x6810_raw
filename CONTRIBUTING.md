# Contribuir

Usa Python 3.11+, Git LFS y `python scripts/validate.py` antes de cambiar releases.
Mantén los dos comandos públicos pequeños y añade perfiles completos de firmware
con SHA-256, procedencia y evidencia. Conserva el ID compartido del módulo.
Los scripts de diagnóstico e investigaciones no deben volver a `scripts/`.
No publiques capturas, trazas, seriales, preferencias privadas ni rutas personales.
Separa evidencia histórica, validación local y pruebas nuevas en hardware.
Los cambios GCam pertenecen a [su repositorio](https://github.com/SRE-0/infinix_x6810_gcam_port).
