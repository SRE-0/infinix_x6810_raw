# Module catalog

Complete RAW module source trees are in [`modules/`](../modules/README.md):

- `v001_x6810_GL_raw_hd48_12mp_torch_single_flash_apis_changes/` — current
  version with TORCH and SINGLE APIs.
- `v000_x6810_GL_raw_hd48_12mp_torch_changes/` — previous complete version.

Historical full snapshots are under [`archive/modules/`](../archive/README.md).
The manually triggered GitHub workflow packages v000 or v001 as a release ZIP;
generated ZIPs are not kept in the source tree. See the
[installation guide](es/INSTALLATION.md) or [English guide](en/INSTALLATION.md).
