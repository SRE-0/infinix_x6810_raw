# Installation

The current installation and recovery steps are maintained in both languages:

- [Instalación y recuperación (español)](es/INSTALLATION.md)
- [Installation and recovery (English)](en/INSTALLATION.md)

Install complete ZIPs from a GitHub release and verify them against the
release's `SHA256SUMS.txt`. The RAW module and the separate GCam system-app module
have different compatibility checks and recovery steps.
