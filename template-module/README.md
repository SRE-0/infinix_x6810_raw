# SRE-0 Magisk/APatch module template

[Spanish version](README.es.md)

Builds use the shared functions and metadata in customize.sh. Module-specific logic replaces the example installer sequence, preserving the banner, dynamic name frame, manager detection, numbered steps and footer. Boot scripts come from the project, rather than the template examples.
